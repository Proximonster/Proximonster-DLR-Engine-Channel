# One-time GitHub setup

Repository name:

`Proximonster-DLR-Engine-Channel`

Recommended visibility: **Public** if the repository is being used with GitHub Free, because GitHub Pages for Free is available for public repositories. GitHub Pages content is public on the internet.

After creating the empty repository, upload the contents of this kit to the repository's `main` branch.

Then configure:

`Settings` → `Pages` → `Build and deployment` → `Source: Deploy from a branch` → `Branch: main` → `Folder: /(root)` → `Save`.

The channel endpoint will be:

`https://<github-owner>.github.io/Proximonster-DLR-Engine-Channel/channel.json`

Do **not** put `channel.json` online until its package ZIP is also present and the SHA-256 has been generated by the build script. Otherwise Proximonster may see a channel entry that cannot be downloaded.
